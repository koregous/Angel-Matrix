# Credits

- **Code:** MIT licensed, see `LICENSE`. The font below keeps its own licence.

- **Font:** Press Start 2P by CodeMan38, released under the SIL Open Font License 1.1
  (check the licence text when you add the font file to `assets/fonts/`).
- **Glyph alphabet:** generated by this project's own seeded algorithm
  (`src/generators/glyphs.js`). It is plain procedural code, not an image model. The 64 glyphs are
  locked by `tests/glyphs.test.js`; a rendered sheet is in `docs/`.
- **Sound effects:** synthesised at runtime with the Web Audio API (`src/audio/synth.js`).
- **Music:** supplied by the player. No music is bundled.
